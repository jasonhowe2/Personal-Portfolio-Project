## Featured Project
**Research question:** To what extent have changes in modern pitching affected batting average and offensive production in Major League Baseball from 2000 to 2025?

The analysis combines MLB Stats API traditional batting and pitching statistics for 2000–2025 with Baseball Savant four-seam fastball velocity data for 2008–2025.

## Main Findings
- Average four-seam velocity increased 2.50 MPH from 2008 to 2025.
- Pitching K% increased 4.69 percentage points.
- AVG changed by -0.019.
- OPS changed by -0.030.
- Velocity vs. OPS correlation: r = -0.263.
- K% vs. AVG correlation: r = -0.932.
- K% vs. OPS correlation: r = -0.581.

These results describe associations rather than causal effects.
